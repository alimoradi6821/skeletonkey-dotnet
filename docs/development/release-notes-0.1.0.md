# SkeletonKey 0.1.0

SkeletonKey `0.1.0` is the first GA Windows x64 release of the deterministic workflow automation engine and Runner.

The release includes graph workflow execution, validation/planning, built-in control flow, durable integrity-protected checkpoints, safe retry and crash recovery, Playwright Chromium automation, essential FlaUI desktop automation, local hash-verified plugins, filesystem artifacts, self-contained Runner packaging, SBOM/provenance, resource-leak soak testing, and blue/green SellerBot Agent deployment with rollback.

Phase 30 additionally freezes the `0.1.x` compatibility surface and maps unavailable checkpoint/artifact persistence to stable fail-closed error codes.
