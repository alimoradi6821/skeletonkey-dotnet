# Locator Schemas

`schemas/locators/0.1/schema.json` is the normative JSON Schema Draft 2020-12 artifact for SkeletonKey locator documents version `0.1.0`.

The schema is hand-maintained, uses local `$defs` references only, and defines document identity, locator IDs, cardinality, scoping, and semantic-first strategy shapes. It does not execute selectors or resolve locator catalogs.
